# Security policy

## Supported versions

Please report security issues affecting the latest released version of Train Planning Tools. Older releases may not receive fixes; update to the latest release before reporting where possible.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository (Security tab → **Report a vulnerability**) so the maintainer can investigate privately. If private reporting is unavailable, contact the maintainer through their GitHub profile to arrange private disclosure. Avoid including real timetable, train-plan, or other sensitive operational data; use synthetic examples instead.

Please include the affected version, Windows/Python environment if relevant, steps to reproduce using synthetic data, and the potential impact. Do not publish exploit details until a fix or coordinated disclosure has been agreed.
